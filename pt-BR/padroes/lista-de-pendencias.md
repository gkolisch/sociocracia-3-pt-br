# Lista de pendências

Mantenha uma lista atualizada de coisas que você precisa tratar, para lembrá-las, e use essa informação para planejar e organizar seu trabalho.

*Uma **lista de pendências** é uma lista de itens de trabalho não concluídos, muitas vezes priorizados, normalmente um entregável, requisito ou motivador, que precisam ser tratados.*

As listas de pendências estão no centro de qualquer sistema confiável e transparente de organização do trabalho e da governança. Considere tornar as listas visíveis, não só para os membros de uma equipe, mas também para a organização mais ampla.

Em vez de se desviar quando surge um novo item de trabalho, anote-o na lista de pendências adequada, para manter o foco no trabalho em andamento.

Tipos de lista de pendências incluem:

- lista de pendências de *governança*
- lista de pendências de *operações*
- lista de pendências de *sprint*
- lista de pendências de produto
- lista de pendências de impedimentos

**Implementação:**

- **lista analógica:** notas adesivas na parede, ou fichas, ímãs e quadro branco
- **lista digital:** por exemplo [Google Sheets](https://www.google.com/sheets/about/), [Trello](https://trello.com/), [Kanban Flow](https://kanbanflow.com/), [Jira](https://www.atlassian.com/software/jira), [Asana](https://asana.com/)

Cada item de uma lista priorizada normalmente contém:

- uma **descrição curta** do item de trabalho, normalmente um *entregável*, *requisito* ou *motivador*
- referência a outros **itens de trabalho interdependentes** ou projetos, e a qualquer **outra informação relevante**
- uma **estimativa do tempo** necessário para tratá-lo

Também pode ser útil incluir:

- uma data-limite, se necessário
- uma forma de visualizar a ordem ou as prioridades

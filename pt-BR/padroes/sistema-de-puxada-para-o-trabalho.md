# Sistema de puxada para o trabalho

As pessoas puxam novos itens de trabalho quando têm capacidade, em vez de receber trabalho empurrado ou atribuído a elas.

Priorize os itens de trabalho pendentes para garantir que os importantes sejam feitos primeiro.

Puxar o trabalho evita sobrecarregar o sistema, sobretudo quando o *trabalho em andamento (WIP) por pessoa ou equipe é limitado*.

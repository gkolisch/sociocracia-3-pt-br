# Resolver objeções

Use a informação revelada por uma objeção para identificar formas de evoluir propostas, políticas e ações até um estado bom o bastante.

### Visão geral

Normalmente é mais eficaz **tratar uma objeção de cada vez**, criar uma proposta de emenda, resolver quaisquer objeções a essa emenda e depois seguir para a próxima objeção à proposta geral.

Uma proposta se torna política quando todas as objeções foram resolvidas.

As objeções são resolvidas emendando a proposta. As **emendas** podem incluir o seguinte:

- adicionar, remover e/ou mudar algo na proposta.
- adiar a resolução de uma objeção específica para depois. Lembre-se de esclarecer quem assumirá a responsabilidade, até quando e o que acontecerá depois.
- (co)criar uma nova proposta no futuro, se isso for considerado mais eficaz do que continuar a trabalhar na proposta existente.
- delegar a tarefa de revisar, pesquisar e/ou propor uma emenda para uma ou até várias objeções relacionadas a um indivíduo ou grupo.
- deixar a proposta principal inalterada e monitorar o resultado, porque o esforço, ou o custo de mudar as coisas para resolver a objeção, supera os benefícios ou ganhos previstos.
- pedir feedback ou contribuição a um delegador, por exemplo ao acordar uma estratégia para um subdomínio.
- dedicar mais tempo à reflexão e voltar à objeção depois.

Há sempre algum próximo passo iterativo que você pode dar! Mesmo que uma proposta não trate por completo o *motivador* ou não cumpra o *requisito* correspondente, chegar a um acordo sobre **um ou mais próximos passos iterativos** muitas vezes é bom o bastante. Às vezes também ajuda dividir as coisas em passos pequenos, sobretudo em situações complexas ou complicadas.

As objeções podem ser resolvidas seguindo o processo descrito na *Tomada de decisão raciocinada*:

**Passo 1:** crie uma proposta de emenda.

**Passo 2:** entenda a emenda proposta.

**Passo 3:** verifique se há possíveis objeções à emenda proposta, por exemplo com sinais com as mãos. As possíveis objeções são apresentadas no Passo 4.

Se não houver possíveis objeções, siga para o passo 6 (Celebre). Caso contrário, trate uma possível objeção de cada vez e:

**Passo 4:** ouça o raciocínio da possível objeção e *determine se o argumento apresentado tem validade*.

**Passo 5:** integre qualquer informação revelada na etapa anterior para melhorar a emenda proposta, depois volte ao passo 3.

**Passo 6:** celebre! Vocês acordaram uma emenda que resolve a objeção!

Abaixo há mais orientações sobre como percorrer cada passo. Este processo pode ser repetido até todas as objeções serem resolvidas. Como em todos os padrões do S3, sua abordagem para resolver objeções pode ser ajustada ao seu contexto.

### Passo 1: crie uma proposta de emenda

*Crie uma sugestão de como emendar a proposta para resolver a objeção, com base na informação que a objeção revela.*

Há muitas formas de criar uma emenda. Abaixo estão algumas opções típicas. Recomendamos usá-las na ordem apresentada: se a primeira não funcionar, vá para a próxima, e assim por diante. Quando você se familiarizar com o processo, saberá discernir no momento qual opção é mais adequada.

1. Pergunte a quem levanta a objeção: "*Você tem uma sugestão de como emendar esta proposta para resolver esta objeção?*"
2. Pergunte ao grupo: "*Alguém tem uma sugestão de como emendar esta proposta para resolver esta objeção?*" e escolha uma pessoa para apresentar a sugestão.
3. Se for difícil criar uma emenda de imediato, convide um diálogo com bloco de tempo para compartilhar ideias, com o objetivo de chegar a uma emenda a partir dali.

Como em qualquer proposta, uma sugestão de emenda dá um ponto de partida que pode ser refinado convidando e resolvendo objeções (ver Passo 4: teste se um argumento qualifica como objeção).

Muitas vezes ajuda repetir ou resumir a emenda e escrevê-la para todos verem.

### Passo 2: entenda a emenda

*Garanta que todos entendem a emenda proposta.*

**O facilitador pergunta:** *Alguma pergunta para entender a emenda proposta?*

Dicas para todos:

- Mantenha suas perguntas e respostas breves e diretas.
- Evite entrar em discussões ou expressar opiniões sobre a validade da emenda nesta etapa. O ponto aqui é apenas garantir que a emenda sugerida está clara.
- Adicione esclarecimentos relevantes à emenda escrita.

### Passo 3: verifique possíveis objeções

*As pessoas consideram a emenda proposta e indicam se têm possíveis objeções ou preocupações.*

Esta etapa é apenas para identificar quem tem possíveis objeções ou preocupações. Os argumentos são ouvidos na próxima etapa.

**O facilitador pergunta:** *Há possíveis objeções ou preocupações a esta emenda?* Observe que o assunto aqui é a emenda, não a proposta inteira!

Muitos grupos usam sinais com as mãos para indicar rápida e claramente se alguém tem possíveis objeções.

- Se houver possíveis objeções à emenda sugerida, siga para a próxima etapa (*Teste se um argumento qualifica como objeção*).
- Se ninguém indicar possíveis objeções, vá para o **Passo 6: celebre**, porque vocês acordaram a emenda.

### Passo 4: teste se um argumento qualifica como objeção

Consulte *Testar se argumentos qualificam como objeções*.

- Se o argumento qualificar, continue para o **Passo 5** (Resolva uma objeção).
- Se o argumento não qualificar, volte ao **Passo 3** para verificar se há mais possíveis objeções à emenda proposta.

### Passo 5: resolva uma objeção

*Repita o processo: use o padrão Resolver objeções para resolver uma objeção à emenda.*

Crie uma emenda à emenda atual! Lembre-se de que uma emenda proposta pode incluir a sugestão de substituir a emenda atual por outra.

Como você pode ver, o padrão Resolver objeções pode ser usado de forma recursiva.

### Passo 6: celebre!

Vocês acordaram uma emenda que resolve a objeção! Antes de seguir, lembre-se de atualizar a proposta original para integrar a emenda acordada.

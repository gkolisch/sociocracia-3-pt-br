# Testar se argumentos qualificam como objeções

Use bem seu tempo e seus recursos limitados: teste se os argumentos qualificam como objeções e aja apenas sobre os que qualificam.

### Visão geral

Quando alguém levanta uma possível objeção, ou seja, um argumento para mudar algo, verifique se o argumento revela como manter as coisas inalteradas vai, ou pode, levar a consequências que você quer evitar. Ou se ele informa uma forma válida de melhorar como alcançar seus objetivos.

Explore e refine cada argumento conforme necessário para identificar ideias equivocadas ou mal-entendidos. Elimine também os aspectos do argumento que se baseiam apenas em suposições, preferência pessoal ou opinião. Se você estabelecer que o que resta do argumento qualifica como objeção, siga para *resolver a objeção*.

### Trabalhar com argumentos

Para ter um diálogo produtivo, ajuda entender que todo argumento é formado por uma série de **afirmações**. Cada argumento contém uma ou mais **premissas**, oferecidas como razões para aceitar uma **conclusão**.

Cada premissa de um argumento pode ser examinada individualmente. Quando fazemos isso, podemos analisar se a conclusão que decorre dessas premissas resistiu ao teste.

Ajuda apresentar o argumento de um modo que torne as premissas e a conclusão óbvias, por exemplo assim:

1. Primeira premissa
2. Segunda premissa
— — — — — — — —
**Portanto**: conclusão

**Facilitador:** convide o grupo a listar as premissas e explicar a conclusão, e siga a partir daí.

Às vezes ajuda registrar essa informação em um flip chart ou quadro branco digital, ou até como texto em um chat.

Com um argumento exposto assim, o grupo pode focar perguntas para entender o argumento segundo cada afirmação específica, e apontar as afirmações com que não concorda. Cada discordância pode ser apresentada usando o mesmo método acima.

Quando uma premissa for acordada, marque-a como resolvida. Quando o diálogo revelar uma premissa oculta, simplesmente adicione-a à lista. Se uma premissa se revelar inválida, remova-a. Registrar o progresso assim ajuda a garantir que todos estejam alinhados com o estado atual do argumento.

**Quando o acordo parece fora de alcance:** em um grupo, às vezes é impossível resolver de imediato uma discordância sobre uma afirmação específica ligada a uma possível objeção. Isso costuma acontecer porque o grupo não tem dados, conhecimento ou experiência. Nesses casos, uma forma de lidar é reenquadrar a possível objeção em torno daquela incerteza específica. Se o argumento alterado qualificar como objeção, ele pode ser resolvido alterando a proposta com uma provisão adicional para estabelecer os fatos sobre a afirmação controvertida.

### Um processo para testar se um argumento qualifica como objeção

Este processo é uma variação do padrão *Tomada de decisão raciocinada*.

**Passo 1:** apresente o argumento levantado como possível objeção.

**Passo 2:** entenda o argumento.

**Passo 3:** verifique se há discordância de que o argumento qualifica como objeção, por exemplo com as mãos levantadas. As razões das discordâncias são apresentadas na próxima etapa.

- Se não houver discordância, **o argumento qualifica como objeção**, e você pode seguir para *resolver a objeção*.
- Caso contrário, trate uma possível discordância de cada vez e:

**Passo 4:** investigue o raciocínio por trás da discordância:

- Se ele demonstrar que o argumento original é falso, total ou parcialmente, ou que, apesar de ser sólido, não qualifica como objeção, siga para a próxima etapa.
- Caso contrário, volte ao passo 3 para verificar outras discordâncias.

**Passo 5:** integre a informação revelada na etapa anterior ao argumento original:

- Se o argumento original ainda tiver alguma validade, refine-o e continue com o passo 3 para ver se há discordância do argumento refinado.
- Caso contrário, você demonstrou que o argumento original **não é uma objeção**.

Abaixo há mais orientações sobre como percorrer cada passo. Como em todos os padrões do S3, sua abordagem para testar se argumentos qualificam como objeções pode ser ajustada ao seu contexto.

#### Passo 1: apresentar o argumento

*Apresente o argumento levantado como possível objeção.*

**O facilitador pergunta** à pessoa com a possível objeção: *Por favor, explique seu argumento.*

#### Passo 2: entender o argumento

*Garanta que todos entendem o argumento.*

**O facilitador pergunta a todos:** *Alguma pergunta para entender o argumento?*

**Todos:** se você não entender, entre e faça uma pergunta de esclarecimento. A pessoa que apresenta o argumento explica mais, até todos entenderem.

#### Passo 3: verificar discordância do argumento

*As pessoas consideram o argumento e indicam se discordam.*

**Todos:** reflita consigo mesmo se o argumento apresentado qualifica como objeção ou não.

**Nota:** se o grupo é novo no processo, o facilitador pode convidar todos a refletir explicitamente: *Você acha que este argumento qualifica como objeção?*

**O facilitador pergunta:** *Alguém discorda, total ou parcialmente, de que este argumento qualifica como objeção? Se sim, levante a mão.*

- Se ninguém discordar: **o argumento qualifica como objeção.** Siga para *resolver a objeção*.
- Se alguém discordar: continue para a próxima etapa.

#### Passo 4: investigar o raciocínio por trás de uma discordância

Escolha uma das pessoas com a mão levantada e, usando o mesmo processo de testar argumentos, determine se as razões dela para discordar são válidas ou não:

**4.1. Apresentar a razão da discordância**: o facilitador convida: *Por favor, explique por que o argumento original está total ou parcialmente incorreto.*

**4.2. Entender a razão da discordância**: o facilitador convida: *Alguma pergunta para entender este argumento?*

**4.3. Verificar discordância da discordância:** o facilitador pergunta: *Alguém discorda, total ou parcialmente, de que este argumento é válido?*

- **Se ninguém discordar**: o argumento da discordância é considerado válido. Vá para o passo 5.
- **Se alguém discordar**: investigue o raciocínio por trás da discordância (ver passo 4) até chegar a um argumento com o qual ninguém discorde. Depois, retome cada argumento anterior, um por vez, verificando se resta algo e/ou se ele precisa ser mudado ou descartado (ver passo 5 para orientações), até voltar à discordância inicial.

#### Passo 5: integrar a informação revelada na etapa anterior ao argumento original

**O facilitador pergunta** a quem apresentou o argumento original: *"Resta algo do seu argumento?"*

Quem trouxe o argumento original pode refiná-lo, reformulá-lo ou reenquadrá-lo, ou descartá-lo por completo, se não restar nada.

- Se o argumento original ainda tiver alguma validade, refine-o e continue com o passo 3 para ver se há discordância do argumento refinado.
- Caso contrário, você demonstrou que o argumento original **não é uma objeção**.
